# Task 8 – Exploratory Data Analysis (EDA)

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Students Performance dataset using Python. The main objective is to understand student performance, analyze subject-wise scores, identify patterns, and visualize the data using graphs.

## Dataset
**Dataset Name:** StudentsPerformance.csv

The dataset contains student information and marks in three subjects:
- Math Score
- Reading Score
- Writing Score

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Objectives
- Load and explore the dataset.
- Understand dataset structure and statistical information.
- Check missing values and duplicate records.
- Calculate total score, percentage, and average score.
- Analyze subject-wise average marks.
- Compare student performance based on gender.
- Visualize score distributions.
- Identify outliers using boxplots.
- Analyze correlations between subjects.
- Study pass and fail percentages.
- Analyze performance based on test preparation courses.

## Exploratory Data Analysis

### 1. Dataset Information
Displays the dataset shape, column names, data types, and statistical summary.

### 2. Missing Values Analysis
Checks missing values in the dataset.

### 3. Total Score and Percentage
Calculates the total score, percentage, and average marks of students.

### 4. Subject-wise Average
Analyzes the average marks obtained in math, reading, and writing.

### 5. Gender-wise Performance
Compares the average scores of students based on gender.

### 6. Score Distribution
Uses histograms to visualize the distribution of math, reading, and writing scores.

### 7. Outlier Analysis
Uses boxplots to identify score distributions and possible outliers.

### 8. Correlation Analysis
Uses a heatmap to understand relationships between subject scores.

### 9. Pass and Fail Analysis
Analyzes student pass and fail percentages based on the three subject scores.

### 10. Test Preparation Analysis
Compares student performance based on test preparation course completion.

## How to Run the Project

1. Download or clone the repository.
2. Open Google Colab.
3. Upload `StudentsPerformance.csv`.
4. Open `Task8_EDA.ipynb`.
5. Run all cells from top to bottom.
6. View the generated graphs and analysis results.

## Conclusion
This project provides insights into student performance through Exploratory Data Analysis. It helps understand subject-wise scores, gender-wise performance, score distributions, correlations, pass and fail percentages, and the impact of test preparation courses.
